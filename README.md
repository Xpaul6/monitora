# Monitora
Система учета и анализа мощностей хостинг-провайдера. Создана для простого наблюдения за использованием ресурсов серверов.

## Особенности
 - Сбор данных с серверов с помощью [агентов](https://github.com/xpaul6/sysinfo_agent)
 - Хранение данных в time-series таблице (TimeScaleDB)
 - Отбор логов за любой временной период
 - Простой интерфейс с отрисовкой графиков

## Архитектура
Агентская и серверная часть написаны на Go с использованием Gin и GORM. Связь между агентами с сервером осуществляется с помощью HTTP-запросов. Клиентская часть написана на Svelte 5. Для построения графиков используется Chart.js. Серверная и клиентская часть объединены с помощью Docker Compose для простого деплоя.
